### STEP 5 — Notification System

#### T12: Permission + Channels

**Modify:** `AndroidManifest.xml` — add POST_NOTIFICATIONS permission

**Create:** `core/notification/NotificationHelper.kt`

Singleton that creates 3 channels (TASK_REMINDERS, BOSS_DEADLINES, ENERGY_FULL) and provides showTaskReminder(), showBossDeadline(), showEnergyFull() methods.

#### T13: SettingsDataStore Preferences

**Modify:** `SettingsDataStore.kt`

Add keys: TASK_REMINDERS_ENABLED, BOSS_ALERTS_ENABLED, ENERGY_NOTIFICATIONS_ENABLED, REMINDER_HOUR, REMINDER_MINUTE

Add Flow properties and setter functions.

#### T14: Notification Workers

**Create:**
- `core/work/TaskReminderWorker.kt` — daily, checks pending tasks, fires notification
- `core/work/BossDeadlineCheckWorker.kt` — daily, checks active boss deadline within 1 day
- `core/work/EnergyFullCheckWorker.kt` — every 30 min, fires when energy = 100

All use @HiltWorker + @AssistedInject + CoroutineWorker pattern.

#### T15: Worker Scheduling

**Modify:**
- `WorkerModule.kt` — add enqueueTaskReminder(), enqueueBossDeadlineCheck(), enqueueEnergyFullCheck()
- `PhoenixApp.kt` — call new enqueue functions in onCreate()

#### T16: Permission Request + Settings UI

**Modify:**
- `SettingsViewModel.kt` — add notification preference state flows and toggle functions
- `SettingsScreen.kt` — wire toggles to real state, remove "Coming soon", add Energy toggle, use RequestPermission launcher
